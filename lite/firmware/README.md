# NF-3D Lite firmware (ESP32 + Xbox controller)

The Lite flies in **angle mode**. The right stick tilts the drone and you hold the height with the right trigger. It has no flow sensor, ToF sensor or barometer, so there is no position or altitude hold.

| Part | What it is | Checked how |
|---|---|---|
| `libraries/nf_core` | neuroflight-fc's portable core: Mahony filter, gyro calibration, rate PID, mixer. Copied by `sync_core.sh`. `vehicle_params.hpp` is generated by `gen_params.py` from the vehicle the sim flew. | neuroflight-fc's own tests, plus the tests below |
| `libraries/lite_fc` | `FlightCore`: angle mode, stick mapping, arming and failsafe. No hardware calls. | `tests/run.sh`: the angle law matches `lite/fly.py` to within 2e-6. There are arming tests and closed-loop tests for takeoff, a knock, stick directions and link loss. |
| `lite_fc/lite_fc.ino` | Hardware glue: MPU-6050 over I2C, 1 kHz task on core 1, 20 kHz PWM, Bluepad32, LED, serial. | Syntax-checked against mocks only. **It has not been compiled for the ESP32 yet**, because the toolchain download isn't allowed from the cloud environment. Compile it once in the Arduino IDE (below). |

## Flashing (Arduino IDE 2)
1. Under Preferences → Additional boards manager URLs, add the Bluepad32 ESP32 board package URL from the
   Bluepad32 docs ("Arduino + ESP32" section). Then install **esp32_bluepad32** in the Boards Manager.
2. Copy `libraries/nf_core` and `libraries/lite_fc` into your `Documents/Arduino/libraries/`.
3. Open `lite_fc/lite_fc.ino`, pick board **ESP32 Dev Module** and the right COM port, then press Upload.
4. If the compile fails on a Bluepad32 call (`hasData`, `miscButtons`, `playDualRumble` or
   `enableVirtualDevice`), your package version names it differently. Open
   *File → Examples → Bluepad32 → Controller* and use the names it uses. The Menu button is bit 2 (`0x04`) of
   `miscButtons()`.

## Controls (Xbox)
- **Right trigger**: throttle. Hover is at about 60 %.
- **Right stick**: tilt, up to 30°.
- **Left stick left/right**: yaw.
- **Menu**: arm. It only arms when the trigger is released, the drone is level and still, and the battery is above 3.3 V.
- **B**: kill the motors, at any time.

The motors also stop if the controller goes silent for 250 ms, if the drone is tilted past 75° for 0.3 s (a crash), or if it sits armed at zero throttle for 5 s.

LED on the board:
- Fast flicker: calibrating, so keep it still.
- Short blip every 2 s: no controller. Hold the Xbox pair button.
- Slow blink: ready to arm.
- Solid: armed.
- Double blink: battery low. The controller also rumbles.

## Regenerating after a design change
```
python -m lite.checks && python -m lite.fly && python -m lite.firmware.gen_params
python -m lite.firmware.tests.gen_fixture && lite/firmware/tests/run.sh
```
